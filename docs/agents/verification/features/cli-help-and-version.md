# CLI help and version

Every agent-proxy command explains itself with `--help`, the CLI reports its version with `--version`, and it prints shell completion scripts. Running it with no subcommand shows help; an unknown subcommand shows help plus an error and exits non-zero.

## Sub-features

- `help-root` lists subcommands and global flags.
- `help-command` describes one subcommand's flags.
- `version` prints `agent-proxy v<version>`.
- `completions` prints a completion script for a named shell.
- `unknown-subcommand` rejects a mistyped subcommand.

## How to get to it (user POV)

- Run `agent-proxy` with no subcommand, `agent-proxy --help`, or `agent-proxy -h`.
- Run `agent-proxy <subcommand> --help`.
- Run `agent-proxy --version` or `agent-proxy -v`.
- Run `agent-proxy --completions <bash|zsh|fish|powershell|sh|pwsh>`.

## Driving it with verify

Preconditions:

- `verify doctor` is all `ok`.

- **Root help.** Run `verify cli -- --help`. Exit `0`; stdout has `USAGE`, `GLOBAL FLAGS`, and a `SUBCOMMANDS` section listing `info`.
- **Short flag.** Run `verify cli -- -h`. Same output as root help.
- **No subcommand.** Run `verify cli`. Exit `0`; same output as root help.
- **Command help.** Run `verify cli -- info --help`. Exit `0`; stdout has `USAGE` with `agent-proxy info` and a `FLAGS` section listing `--json`.
- **Version.** Run `verify cli -- --version` and `verify cli -- -v`. Exit `0`; stdout matches `agent-proxy v<major>.<minor>.<patch>`.
- **Completions.** Run `verify cli -- --completions zsh`. Exit `0`; stdout is a zsh completion script that mentions `agent-proxy` and `info`.
- **Unknown subcommand.** Run `verify cli -- bogus`. Exit `1`; stderr contains `Unknown subcommand "bogus"`.

## Gotchas

- Help and version text are generated by `effect/cli` from command descriptions, so a missing description shows up here first.
- With no subcommand the CLI prints root help and exits `0`, while an unknown subcommand prints help and exits `1`. Assert the exit code, not just the help text.
